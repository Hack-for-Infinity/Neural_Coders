WCAG 2.1 Foundation

Four Principles. One Standard.

Every accessibility requirement traces back to these pillars. Master them and every design decision becomes clearer.

  • P

    Perceivable

    Content must be presentable in forms users can perceive. Text alternatives, captions, adaptable layouts, and sufficient contrast all live here.

  • O

    Operable

    All functionality must be reachable via keyboard. No time traps, clear navigation, and enough time for users to read and interact.

  • U

    Understandable

    Text must be readable and predictable. Forms must have labels, errors must be described, and instructions must be clear.

  • R

    Robust

    Content must work with current and future assistive technologies. Proper semantics, valid HTML, and ARIA where needed make this possible.

What We Verify

The OpenDoor WCAG Checklist

Key success criteria our platform checks automatically across every page.

  • ✓
    1.1.1 — Non-text Content All images, icons, and charts have meaningful alt text or are marked decorative.
  • ✓
    1.4.3 — Contrast (AA) Normal text at 4.5:1, large text at 3:1 minimum contrast ratio.
  • ✓
    2.1.1 — Keyboard Access Every interactive element reachable and operable via keyboard alone.
  • ✓
    2.4.1 — Bypass Blocks Skip navigation link provided to bypass repetitive content.
  • ✓
    2.4.7 — Focus Visible Keyboard focus indicator clearly visible on all focusable elements.
  • ✓
    3.3.1 — Error Identification Form errors identified in text with specific, actionable descriptions.
  • ✓
    4.1.2 — Name, Role, Value All UI components have accessible names, roles, and state via ARIA.
  • ✓
    4.1.3 — Status Messages Dynamic updates announced to assistive technologies via live regions.
